## 2026-07-08-22 - 小助手设置精简与 npm 安装链路

- 用户目标：精简小助手设置页为 4 个互斥展开 bar，侧边栏底部提供重启后端和安装终端，将 Kimi 安装/升级切到 npm，并让 Explorer 右键菜单名称可编辑。
- 涉及目录：`apps/kimi-shell`、`.ai/architecture`、`.ai/decisions`
- 修改内容：控制中心设置页移除旧快速设置标题、引导步骤标题、顶部保存/菜单和独立详情卡；安装任务改用 `npm install -g @moonshot-ai/kimi-code` / `@latest`；Node ready 改为 22.19+；右键菜单新增 label 设置、预览和保存 command。
- 修改原因：与最新 Kimi Code npm 安装方式及目标 UI 简化方向一致，减少设置页常驻信息噪音。
- 本次已消除的不确定性：官方 Kimi Code 文档要求 npm 安装时 Node.js 22.19+；Windows 首次运行需要 Git for Windows/Git Bash。
- 本次采用的关键假设：缺 Node.js 或 Git Bash 时只提示并提供入口，不自动串联安装；uv/Python 仍作为 legacy optional repair。
- 剩余不确定性：需要真实 Windows Explorer 手工确认自定义菜单名在不同文件/文件夹上下文中显示一致。
- 影响范围：Shell 控制中心 UI、install catalog、install probe、右键菜单注册表写入和 AppSettings schema。
- 验证方式：已通过 `cargo check`、`cargo test --no-run`、`pnpm test`、`.\node_modules\.bin\tsc.cmd --noEmit`、`pnpm check:nfr:security`。
- 是否更新 README：是，更新根 README 和 `apps/kimi-shell/README.md`。
- 是否更新 `.ai/architecture`：是，更新 npm 安装链路和右键菜单 label 持久化事实。
- 是否需要新增或更新 `.ai/decisions`：是，新增 accepted ADR `2026-07-08-context-menu-label-settings.md`。
- 后续注意事项：发布前补做 G3 Explorer 右键菜单和安装包环境手工验收。
