## 2026-07-20-22 - 适配 Kimi Code 0.28.0 web 启动命令

- 用户目标：修复 Kimi Code 升级后后端在健康检查前退出的问题。
- 涉及目录：`apps/kimi-shell/src-tauri/src/backend_manager`、`apps/kimi-shell/docs`、`.ai/architecture`、`tasks`。
- 修改内容：将托管后端命令从 `kimi server run --foreground --port <port>` 替换为 `kimi web --no-open --port <port>`；失败态契约探测改为 `kimi web --help`；同步回归测试和当前文档。
- 修改原因：Kimi Code 0.28.0 已将整个 `kimi server` 命令树替换为固定退出 1 的弃用占位命令，原有 `server run --help` 探测也因占位命令吞掉子命令而产生误导诊断。
- 本次已消除的不确定性：官方 0.28.0 Release、标签源码与本机 0.28.0 CLI 均确认 `web --no-open --port` 是当前前台 Server 契约。
- 本次采用的关键假设：Shell 继续通过持有并终止前台子进程管理自有 Server；不为已弃用命令增加版本分支或回退层。
- 剩余不确定性：无。
- 影响范围：Shell 自有 Kimi 后端的启动和失败诊断；不改变外部实例复用、健康端点、token 传递或停止逻辑。
- 验证方式：`cargo fmt -- --check`、`cargo check`、`cargo test launch_args_enforce_local_only_mode`、`cargo test startup_failure_guidance_distinguishes_contract_results`；使用临时 `KIMI_CODE_HOME` 运行本机 Kimi Code 0.28.0 的 `kimi web --no-open --port 59001`，`/api/v1/healthz` 返回 HTTP 200，随后停止进程并删除临时数据。
- 是否更新 README：是，更新 Shell 运行命令事实。
- 是否更新 `.ai/architecture`：是，更新后端主路径和契约探测事实。
- 是否需要新增或更新 `.ai/decisions`：否，这是跟随上游 CLI 契约的局部兼容修复，不改变本项目架构决策。
- 后续注意事项：升级 Kimi Code 后应优先用具体子命令的 `--help` 和真实健康检查确认契约，不根据旧文档推断。
