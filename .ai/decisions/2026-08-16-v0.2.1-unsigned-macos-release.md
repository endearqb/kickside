# v0.2.1 Unsigned macOS Preview Release

## Status

Accepted

## Context

The normal macOS release path requires Developer ID signing, notarization and stapling. The product
owner explicitly approved `v0.2.1` as another unsigned and unnotarized preview so the Windows DSH
installation, launch and shutdown fixes can be distributed without waiting for Apple credentials.
Tauri updater signing secrets remain configured and are independent from Apple code signing.

## Decision

- Permit exactly the `v0.2.1` tag to build the Apple Silicon `.app` / DMG with Tauri
  `signingIdentity: "-"` and without notarization or stapling.
- Keep the Tauri updater private key and password mandatory for both platform updater artifacts.
- Require the Release body to start with `⚠️ **macOS 版本未签名、未公证**`.
- Label `v0.2.1` as a preview and do not claim Developer ID, notarization, Gatekeeper trust or
  production readiness.
- Keep every later tag fail-closed until signed publication is restored or another exact exception
  is explicitly accepted.
- Publish only after Windows and macOS installers, updater signatures and the cross-platform
  `latest.json` all pass the Release workflow.

## Consequences

- macOS users may need to allow the app manually in System Settings.
- Windows installers still have no Authenticode or SmartScreen reputation from updater signing.
- Automated gates do not replace the remaining Windows/macOS G3 matrix.

## Verification

- Verify tag/package equality, exact `v0.2.1` restriction, warning-first release notes and required
  updater secrets.
- Require CI evidence for NSIS/MSI, app/DMG, ad-hoc/no-Authority macOS identity, updater signatures
  and `latest.json` before publication.
