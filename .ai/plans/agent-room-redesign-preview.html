Agent Room 重设计预览

基于 codex/agent-room-v1 现有实现的界面重构提案：10 个平级 tab 收敛为「主视图 + 房间设置 + 全局资源外迁」，Agent Room 整体改为独立悬浮窗口。视觉沿用仓库 DESIGN.md 的 control-center 语言，不引入新形式。静态稿，按钮不可交互。

01信息架构：10 tab → 3 层

现状
观察发送 Workflow房间 AgentsConnectors 成员Timeline 审批诊断
重构后
主视图（默认）观察 + 发送 + Timeline + 审批合并成一个 IM 式工作面：成员轨看状态，时间线看过程，审批卡内嵌在发生处，底部直接派任务。核心闭环不再切 tab。
房间设置（⚙ 抽屉）房间信息、编排方式、共享背景、成员绑定管理、归档/删除。低频配置收进一个面板，覆盖原「房间 / 成员 / Workflow」三个 tab。
移出房间作用域Agents、Connectors 是全局资源，迁入应用的控制中心（features/control-center 已存在）；诊断收敛为标题栏健康点，点开显示 capabilities / pump / 降级码。
  • 判断依据：10 个 tab 混了四类事——每天用的（观察/发送/Timeline/审批）、偶尔配的（房间/成员/Workflow）、与具体房间无关的（Agents/Connectors）、排障用的（诊断）。放在同一层级，高频操作被低频入口稀释。
  • 最大的流程断点：现在「发送」和「Timeline」是两个 tab——派完任务要切 tab 才能看到结果。合并后派发即所见。
