# Kimi Desktop Shell 发布说明

版本：`v0.0.15`  
发布日期：`2026-03-08`

## 本次更新重点

本版本聚焦“控制中心”安装引导体验的深度优化，实现了安装命令的步骤化展示与全面中文化，并完善了仓库的多语言文档。

## 主要变更

1. 安装命令目录重构与 UI 升级
- **步骤化拆解**：将原本的长脚本拆分为“安装依赖”、“安装 Kimi”、“验证环境”等多个条目，每个条目内部支持按步骤（Step）展示，逻辑清晰、易于跟随。
- **环境自适应展示**：根据用户选择的“官方源”或“镜像源”，自动过滤并仅展示相关的安装条目，减少干扰。
- **手风琴式交互**：弹窗默认采用折叠展示，支持互斥展开，保持界面整洁；新增单步复制功能，大幅降低手动执行时的出错概率。
- **全面中文化**：所有安装指令说明、步骤标题和复制提示均已完成中文本地化。

2. 文档与仓库治理
- **多语言自述文件**：新增仓库根目录 `README_zh.md`，为中文开发者提供更直观的项目概览。
- **元数据同步**：更新应用版本号至 `0.0.15`，并完成全链路配置文件（package.json, Cargo.toml, tauri.conf.json）的同步。

## 安装包

- NSIS：`Kimi Desktop Shell_0.0.15_x64-setup.exe`
- MSI：`Kimi Desktop Shell_0.0.15_x64_en-US.msi`

- `cargo check --manifest-path apps/kimi-shell/src-tauri/Cargo.toml`
- `pnpm -C apps/kimi-shell build`
