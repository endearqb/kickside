# Kimi Shell 版本更新说明

版本：`0.0.3`  
发布日期：`2026-03-05`

## 本次更新摘要

本版本重点修复了 Windows Explorer 右键“文档/文件打开”链路稳定性问题，解决“目录右键正常、文档右键在应用内出现 404”的核心场景，并补充了参数解析可观测性与注册表命令漂移自检能力。

## 主要变更

1. 右键菜单命令一致性增强
- 右键菜单状态判定从“键存在”升级为“键存在 + 命令值匹配预期”。
- 当检测到旧版本残留命令时，会提示可通过“启用右键菜单”进行修复重写。
- 文件右键命令统一升级为：
  - `--open-files -- "%1"`

2. 文件打开参数解析鲁棒性增强
- `--open-files` 支持字面量分隔符：
  - `--open-files -- <path...>`
- 保持兼容旧语法：
  - `--open-files <path...>`
- 支持 `file:///` 形式路径输入。
- 过滤常见 Shell 噪声参数（如 `/prefetch:*`、`/embedding`），降低误解析概率。

3. 安全回退与日志可观测性
- 当 `--open-files` 未解析到有效文件时：
  - 若仅检测到 1 个有效目录，自动降级为 `OpenDir`。
  - 其他情况返回结构化错误信息（含 `first_invalid_token`）。
- 增加 startup / forwarded 请求解析日志，便于现场排查。

4. 文档分流
- 启动白屏问题与右键 404 问题已拆分记录，减少排障混淆。

## 兼容性说明

- 本次为兼容增强发布，现有 `--open-files <path...>` 使用方式继续可用。
- 若本机曾安装旧版右键命令，建议在应用内执行一次“启用右键菜单”以覆盖旧注册表命令值。

## 验证结果

- Rust 单元测试通过（23/23）。
- 重点验证通过：
  - `open_request`：file URI、literal `--`、噪声过滤、目录降级、结构化错误。
  - `context_menu`：命令构造与匹配（含空格与引号路径）。

## 升级建议

1. 升级到 `0.0.3` 后，先在控制中心检查右键菜单状态。
2. 若提示命令漂移，点击“启用右键菜单”完成重写。
3. 再从 Explorer 分别测试目录右键与文档右键链路。
