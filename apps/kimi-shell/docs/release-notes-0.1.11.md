# Kimi Sidekick v0.1.11

## 让每一次工作切换，都更顺手

这一版聚焦桌面工作台的日常体验：窗格、工作区、Skills 和文件预览现在更容易理解，也更不容易在连续操作后“跟丢”当前状态。

## 这次更新带来了什么

- **窗格会跟随当前会话**：在同一个窗格内切换 Kimi Code 会话后，窗格库会同步显示对应的工作目录，减少“看着旧目录、不确定当前在哪”的困惑。
- **Skills 工作区更清爽**：优化来源切换、卡片高度、标签布局和双栏滚动，让技能目录在不同数量、不同长度内容下都保持稳定可读。
- **工作区目标选择更准确**：查看工作区时直接从可用工作区中选择，菜单在内容较多时支持滚动，不再跳到不相关的页面。
- **文件预览更像文件树**：目录和文件按真实层级连续排列，Markdown 的加粗内容也会正确显示；Skill、WorkspaceHub 等入口共享同一套预览体验。
- **Windows 安装包同步升级**：版本号统一为 `0.1.11`，同时提供 NSIS 和 MSI 安装包。

## 安装

- Windows 推荐使用 NSIS：`kimi sidekick_0.1.11_x64-setup.exe`
- 企业部署或统一安装场景可使用 MSI：`kimi sidekick_0.1.11_x64_en-US.msi`
