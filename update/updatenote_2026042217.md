# Update Note

Date: `2026-04-22 17:00`
Version line: `v0.0.38`

## Summary

This update fixes how bundled skills are laid out inside the Windows installer and restores bundled-skill discovery for older installs that still use the legacy `_up_/_up_/_up_/skills` resource path.

## Included Changes

1. **Bundled `skills` now package to the correct resource directory**
- Tauri `bundle.resources` now maps the repo `skills/` directory directly to `resource_dir()/skills`.
- New NSIS builds no longer place bundled skills under `_up_/_up_/_up_/skills`.

2. **Skill Center now supports legacy bundled-skill layouts**
- Bundled skill discovery now checks both:
  - `resource_dir()/skills`
  - `resource_dir()/_up_/_up_/_up_/skills`
- This allows older installed builds to recover the default 5 bundled skills on startup without requiring a reinstall.

3. **Regression coverage for bundled-skill path resolution**
- Added a focused Rust unit test for bundled skill resource candidates.
- Local test binaries compile successfully with `cargo test --no-run`.

## User Impact

- Fresh installers should expose the default bundled skills from the clean `skills` resource folder.
- Older installs that still carry the legacy `_up_` resource layout can now be recognized by Skill Center again.
- The default bundled skills expected in this repo are:
  - `bridge-ops`
  - `docx`
  - `pdf`
  - `pptx`
  - `xlsx`

## Verification
