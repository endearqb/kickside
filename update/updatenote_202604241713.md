# Update Note

Date: `2026-04-24 17:13`
Version line: `v0.0.40` / `v0.0.41`

## Summary

Today's updates move Kimi Desktop Shell toward a quieter setup flow and a more capable local Kimi Web experience. `v0.0.40` introduces the productized local enhanced Web mode and cleans up install/auth/bridge operations. `v0.0.41` follows up by making enhanced Web injection actually run inside the workspace proxy, fixing mode-switch reloads, and modularizing the backend manager.

## Included Changes

1. **Setup actions are more explicit**
- Startup and onboarding no longer auto-run install probes or mirror-health checks.
- Mirror checks now run from explicit user actions.
- Install and upgrade tasks enter their session flow directly instead of doing an extra synchronous probe first.

2. **Login/API default selection is clearer**
- Added `设为默认登录` for returning to Kimi Login as the preferred auth path.
- Provider API selection is now labeled `设为默认 API`.
- Auth state now prefers Provider API only when Kimi Coding Plan API is explicitly selected and configured.

3. **IM Bridge connector management is more predictable**
- The app now allows deleting the last Feishu or Weixin connector.
- Deleted connector secrets are removed with the connector.
- Delete errors use a concise user-facing message instead of exposing backend paths.

4. **Local Enhanced Web mode is available and safer**
- Control Center now exposes `官方 Web` and `本地增强版`.
- Enhanced Web health, source commit, last-known-good commit, fallback reason, and disclaimer are visible in diagnostics.
- Added i18n and compliance checks plus third-party source and license records.

5. **Enhanced Web now uses same-origin injection**
- The follow-up `v0.0.41` change removes the outer wrapper behavior.
- The workspace proxy injects local enhancement scripts and CSS directly into the Kimi Web HTML response when enhanced mode is enabled.
- Switching or falling back between Web modes now remounts the iframe so the page actually reloads with the selected mode.

6. **Backend manager is easier to maintain**
- The large `backend_manager.rs` implementation was split into focused modules for config, install compatibility, lifecycle, system open, workspace proxy, and workspace injection.
- Existing Tauri commands and public behavior are preserved.

## User Impact

- Users see fewer surprise background checks when opening setup screens.
- Switching between Kimi Login and Provider API is less ambiguous.
- Bridge connector lists can now be intentionally emptied for Feishu or Weixin.
- Local enhanced Web mode should now show real in-page Chinese/local enhancements instead of only wrapping the official surface.
- The official Web path remains the stable fallback.
