# Update Note

Date: `2026-04-25 12:48`
Version line: `v0.0.43`

## Summary

Today's update makes the enhanced Kimi Web feel more complete in Chinese and makes the Control Center install flow more direct. `v0.0.43` expands fixed-text injection deeper into the chat workspace, renames the visible `Kimi Code` header to `Kimi 小助手` in enhanced mode, and adds faster entry points for installing Git and Node.js.

## Included Changes

1. **More of the official Web fixed UI is now localized in enhanced mode**
- Added Chinese injection coverage for chat-side system labels such as `Thought`, tool action headers, activity states, prompt-composer helper text, session right-click menu items, and context-usage labels.
- Added limited matching for three stable variable patterns only: `Thought for {n}s`, `{percent}% context`, and `{n} selected`.
- Continued to exclude payload-level content such as approval descriptions, question bodies, model output, user messages, file paths, URLs, and tool arguments.

2. **The visible Kimi Web brand title now reads `Kimi 小助手`**
- The top-left visible title `Kimi Code` is now replaced through same-origin injection.
- The `K` logo image and the version text remain unchanged, so the header becomes `Kimi 小助手 v1.39.x`.
- This change is display-only and does not alter the brand link or upstream asset files.

3. **Installing common dependencies is quicker from Control Center**
- Added direct `安装 Git` and `安装 Node.js` buttons under the main install controls.
- Removed the duplicated optional-enhancement section from the detailed options block.
- Switching to the mirror tab no longer auto-runs mirror detection; users now trigger mirror health checks manually.

4. **Release version has been bumped to 0.0.43**
- Desktop package version metadata is now synchronized to `0.0.43`.
- New NSIS and MSI installers for `0.0.43` are ready for GitHub Release upload.

## User Impact

- Enhanced Web mode now shows a more complete Chinese fixed UI in the main chat area.
- The visible product title is more aligned with the localized desktop shell experience.
- Users who only need Git or Node.js can start those installs directly, without drilling into repeated optional sections.
